# مستكشف إعلانات ميتا (Meta Ads Explorer)

مشروع Next.js يبحث بإعلانات فيسبوك وانستقرام النشطة عبر **Meta Ad Library API** الرسمي والمجاني.

## المزايا الحالية
- بحث بكلمة مفتاحية (اختياري — بيرجع كل الإعلانات لو تركته فاضي) + فلترة حسب الدولة/المنصة/الحالة
- ترتيب (الأحدث/الأقدم) وعدد نتائج قابل للتغيير لكل صفحة
- فلترة فورية ضمن النتائج المعروضة (بدون طلب جديد لميتا)
- عرض شبكة أو قائمة (Grid / List toggle)
- معاينة سريعة داخل نافذة منبثقة (iframe لصفحة ميتا الرسمية)
- **تجسّس براند (Brand Spy)**: صفحة مستقلة تعرض كل إعلانات براند معيّن
- **مجلدات (Folders & Boards)**: إنشاء مجلدات متعددة وحفظ إعلانات بأكثر من مجلد
- **مؤشر أداء حقيقي**: 🔥/🟡/⚪ مبني على مدة عرض الإعلان الفعلية (ليس رقمًا مختلقًا)
- **نسخ نص الإعلان** بضغطة زر
- **تصدير مجلد كامل كملف CSV** (Swipe File جاهز لإكسل)
- **عمليات بحث سابقة** تظهر تلقائيًا
- **فلترة بتاريخ محدد (من/إلى)** ونوع الإعلان (تجاري/سياسي/وظائف/سكن/ائتمان) — فلاتر رسمية من ميتا
- **رسائل خطأ واضحة** (توكن منتهي، تجاوز حد الطلبات، طلب غير صحيح) بدل رسالة عامة
- تحميل المزيد (Pagination)

## الخصوصية
الـ Access Token بينحفظ **فقط** بمتصفحك (`localStorage`). كل طلب بيروح مباشرة
من جهازك إلى `graph.facebook.com` — ما في أي backend وسيط بيشوف أو يخزن التوكن.

## التشغيل محليًا
```bash
npm install
npm run dev
```
افتح http://localhost:3000 — رح يوجهك أول مرة لصفحة "التوكن" لإدخال الـ Access Token.

## الحصول على Access Token
1. سجل على https://developers.facebook.com
2. أنشئ App جديد
3. فعّل صلاحية الوصول لـ Ad Library API
4. انسخ الـ Access Token وحطه بصفحة الإعدادات بالموقع

## قسم تيك توك (مؤجل)
ما في API رسمي مجاني معادل لـ Meta Ad Library بخصوص تيك توك. الخيارات المتاحة
(TikTok Ads Library العامة، أو هاشتاغ #TikTokMadeMeBuyIt) بتحتاج سكرابينغ لصفحات
عامة عن طريق أدوات خارجية، وهاد قرار منفصل رح ناخده لما نوصله — مش مبني بهالنسخة.
